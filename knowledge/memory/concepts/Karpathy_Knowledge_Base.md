# Karpathy Knowledge Base

## Overview

Andrej Karpathy's approach to using LLMs for personal knowledge management.

## Key Steps

- **Data ingest** - Index sources into raw/
- **AI compilation** - LLM compiles into wiki/
- **Q&A over wiki** - Ask complex questions
- **Output as artifacts** - Markdown, slides, images

## Key Insight

The LLM writes and maintains all wiki data. Humans rarely edit directly.
