# Product images

These images were captured from the native Memoria debug app on macOS with
`agent-desktop`, using window-scoped screenshots. The Cedar content is a fictional
manual review fixture, not a transcription-accuracy demonstration.

Images are cropped to the relevant product surface and resized for GitHub. The
hero adds a presentation background around the original screenshot. UI content
has not been replaced, and model outputs and provisional speaker labels are shown
as recorded. No private recordings or voice profiles are included.

Capture date: 1 November 2026. The installed build predates some later responsive
and pluralisation fixes in source. Screenshots illustrate the interface, not a
claim of complete native acceptance or a supported release.

The Summary and Ask images were refreshed from the installed refinement build on
2 November 2026. They show the new hierarchy and shared styling; the remaining
images are earlier captures. All content remains the fictional test scenario.
