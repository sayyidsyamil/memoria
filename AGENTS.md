# Memoria development

Memoria is an FYP2 meeting-intelligence application derived from Tolaria
(https://github.com/refactoringhq/tolaria). Preserve upstream copyright,
AGPL-3.0-or-later licensing, and third-party notices.

## Local workflow

- Work locally. Commit, push, publish, and create remote repositories only when
  explicitly requested by the user.
- Upstream Linear, CodeScene, Codacy, CircleCI, signing, analytics, and release
  accounts are not Memoria project requirements. Do not use upstream accounts.
- Read relevant architecture documentation before structural changes. Reuse
  existing components and visual conventions.
- Preserve existing user work and use disposable vaults for verification.
- Keep product identifiers, imports, localization catalogs, and tests consistent.
- Run appropriate local type checks, builds, and focused tests. Report failures
  and untested native or platform-specific behaviour accurately.
- Keep durable knowledge portable and source citations inspectable.
- Do not claim inherited Tolaria capabilities as original Memoria contributions.

The user approved replacing upstream-specific workflow requirements on
2026-10-30. This fork uses the local workflow above.
